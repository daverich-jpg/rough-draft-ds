# Radius

Two families. **Sharp = zine. Pillowy = UI you touch.** Never mix both on one element.

| Token | Value | Family | Use |
|---|---|---|---|
| `none` | 0 | zine | Posters, quote/zine cards, tape, editorial blocks |
| `nick` | 3px | zine | Tags, stamped labels |
| `sm` | 10px | pillow | Inputs, small buttons, toasts |
| `md` | 16px | pillow | Buttons, cards, tabs |
| `lg` | 24px | pillow | Modals, large cards |
| `xl` | 36px | pillow | Sheets, hero cards |
| `full` | 9999px | pillow | Pills, chips, avatars, toggles, sticker buttons |

**Rule:** if it's editorial (something you *read*), use `none` or `nick`. If you tap it, type in it, or it slides in, use `sm`–`xl`.
