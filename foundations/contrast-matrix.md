# Contrast matrix

Generated by `npm run contrast` (scripts/contrast-report.mjs). Every pairing below is checked on each build; the build fails if a text pair drops under 4.5:1 or a UI pair under 3:1.

Legend: **AAA** ≥ 7 · **AA** ≥ 4.5 · **large only** 3 to 4.5 (≥24px, or ≥18.66px bold) · **AA (UI)** ≥ 3 for borders, icons and focus rings · **FAIL**.
